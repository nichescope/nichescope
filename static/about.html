About NicheScope

A personal Etsy keyword-research tool

NicheScope helps me size up a product niche on Etsy before I commit to it. I type a keyword and it samples current public listings to show how crowded the niche is, what price bands sell, how much interest listings attract (favorites), and which tags dominate the top results.

How it works

It calls the Etsy Open API v3 public listing search with an application key (no OAuth, no access to any member's private data), then computes the statistics locally. Nothing is stored on a server.

Scope & privacy

  • Public endpoints only — no login, no private data.
  • No database, no accounts, no tracking or analytics.
  • Personal, non-commercial tool used only by me.
